Randomised Local Search

The Randomised Local Search algorithm starts with a random permutation of cities as the initial tour. It then makes random swaps of cities in the tour. After each swap, the tour's length is evaluated, and if the new tour is shorter, it is accepted as the current solution. O(n2)

How it works:

  • Initialization: Starts with a tour of a random permutation of cities
  • Random Neighbor Generation: It generates neighboring solutions by making random pairwise swaps of cities in the tour. These swaps are done iteratively to explore different tour arrangements.
  • Evaluation and Acceptance: After each swap, the algorithm evaluates the tour's length. If the new tour is shorter than the previous one, it is accepted as the current solution. Otherwise, it may be accepted with a certain probability based on the difference in tour lengths.
  • Termination: The process of generating and evaluating random neighbors continues for a predefined number of iterations or until no further improvements can be made.

Advantages of Randomised Local Search Algorithm:

  • Exploratory: The Randomised Local Search algorithm explores a wide range of tour configurations, which can help in escaping local optima and finding better solutions.
  • Adaptability: It can be applied to different initial tours, making it adaptable to different scenarios.

Disadvantages of Randomised Local Search Algorithm:

  • Stochastic Nature: The results of the Randomised Local Search algorithm can vary due to its stochastic nature. There is no guarantee that it will find the optimal solution.
  • Time and Iteration Sensitivity: The quality of the solution can be influenced by the number of iterations and the probability of accepting worse solutions.
