Held-Karp Algorithm

The Held-Karp algorithm, also known as the dynamic programming approach, is used to find the exact optimal solution. It works by systematically computing and storing the shortest path lengths for all possible combinations of cities in a dynamic programming table, ensuring a guaranteed optimal result. O(n2 * 2n)

How it works

  • Initialization: The algorithm initialises a dynamic programming table with the smallest subproblem size, where only two cities are considered. It calculates the distance between these two cities and stores it.
  • Dynamic Programming Iteration: The Held-Karp algorithm iteratively fills the dynamic programming table. It systematically considers larger subproblems by incrementally adding more cities to the combinations. It computes the shortest path lengths for all possible combinations of cities and stores them in the table.
  • Optimal Tour Reconstruction: Once the table is fully populated, the algorithm reconstructs the optimal tour by backtracking through the table. It starts at the starting city, considers all possible next cities, and chooses the one that leads to the shortest tour.
  • Optimal Solution: The final result is the optimal TSP tour with the shortest total distance.

Advantages:

  • Optimal Solution: The Held-Karp algorithm guarantees an exact optimal solution for the TSP, making it a reliable choice when optimality is crucial.
  • Versatility: It can handle TSP instances of varying sizes and complexities, making it suitable for a wide range of scenarios.

Limitations:

  • Exponential Time Complexity: The main drawback of the Held-Karp algorithm is its exponential time complexity, which makes it impractical for large TSP instances. The number of subproblems grows exponentially with the number of cities.
  • Memory Requirements: The algorithm requires significant memory to store the dynamic programming table, which can be a limiting factor for large TSP instances.
